# IMDB Top 1000 Movies - Cleaning and Exploratory Analysis

## Project Overview
This is a data cleaning and exploratory analysis of the top 1000 movies ranked by IMDb. The point of this project is to showcase my proficiency in using SQL for data cleaning and analysis.

## Files in This Repository
- `imdb_1000_cleaning.sql` - SQL script containing the data cleaning proccess
- `imdb_1000_analysis.sql` - SQL script containing the exploratory data analysis proccess  

These files are uploaded to the main branch.

- `imdb_1000.csv` - CSV file of raw data used in cleaning
- `imdb_1000_clean.csv` - CSV file of data used in analysis
- `cpi.csv` - CSV file of cpi values from 1947-2025
- `cpi_staging.csv` - prepped CSV file used for analysis prep (adjusting domestic gross box office for inflation)
- 
These files are uploaded to the source branch.
